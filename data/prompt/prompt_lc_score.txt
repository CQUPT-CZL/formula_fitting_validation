任务：评估一段分析的逻辑一致性，分析对象为一个数学公式及其与观测数据之间的偏差。目标是判断分析中的推理是否严谨且前后连贯。

输入：以下是要求和待评估的分析内容：
{instruction}
----------
分析如下：
{predict}
---------

指令：
- 根据“逻辑一致性（LC）”维度进行打分：
  1. 分析步骤之间是否存在**清晰的逻辑联系**；
  2. 是否存在**矛盾、不合理的假设或跳步推理**；
  3. 是否基于前一步的结果合理地得出后续推论。
- 给出 0~10 的整数评分，0 表示完全不符合要求，10 表示完美满足。
- 给出简短评分理由（1~2 句话）。

输出格式为：
```json
{
  "LC": {
    "score": 整数,
    "reason": "评分理由"
  }
}
