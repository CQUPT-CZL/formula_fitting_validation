任务：评估一段分析的质量，该分析针对一个数学公式（具体公式在输入中提供或隐含），旨在分析公式计算结果与观测数据的偏差并推导修正公式。分析应包含合理且必要的步骤，例如但不限于偏差计算、模式观察、变量关系分析、公式推导和验证，步骤需逻辑清晰且全面。


输入：以下是要求和待评估的分析内容：
{instruction}
----------
分析如下：
{predict}
---------


指令：
- 根据以下两个指标评估输入分析的质量：
  1. **步骤完整性（SC）**：分析是否包含合理且必要的步骤以完成偏差分析和公式修正任务？步骤是否逻辑清晰、覆盖关键分析环节（例如偏差计算、模式识别、变量分析、公式推导等）？不需要遵循特定步骤列表，但应确保分析过程全面。
  2. **逻辑一致性（LC）**：分析的步骤是否逻辑连贯？是否存在矛盾或不合理的假设？推理是否基于前一步的结果？
  3. **分析清晰度（CA）**：分析的表述是否清晰易懂？是否使用结构化的方式（如分段、编号）呈现推理？是否避免冗余或模糊？
- 为每个指标打分（0~10），0 表示完全不符合要求，10 表示完美满足要求。
- 为每个指标提供简短的评分理由（1-2 句话）。

  ```json

      "score": 整数,
      "reason": "评分理由"
    }},
    "LC": {{
      "score": 整数,

    }}
    "CA": {{
      "score": 整数,
      "reason": "评分理由"
    }}
  }}
