任务：评估一段偏差分析的表达清晰度。分析对象为某数学公式与观测数据的偏差及其修正过程。

输入：以下是要求和待评估的分析内容：
{instruction}
----------
分析如下：
{predict}
---------

指令：
- 根据“分析清晰度（CA）”维度进行打分：
  1. 表述是否**清晰易懂**，句式是否通顺；
  2. 是否使用**结构化方式**（如分段、编号）表达分析；
  3. 是否避免冗余、歧义或模糊的描述。
- 给出 0~10 的整数评分，0 表示完全不符合要求，10 表示完美满足。
- 给出简短评分理由（1~2 句话）。

输出格式为：
```json
{
  "CA": {
    "score": 整数,
    "reason": "评分理由"
  }
}
